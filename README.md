## Scope and Method

This list was compiled from a scan of the top level of the `E:\` drive (my Windows software drive) on 2026-09-15. One row is one installed program found there.

Windows system folders and non-software entries were left out: `$RECYCLE.BIN`, `Config.Msi` and `System Volume Information` (system data), plus `0-cargo-target` (a Rust build output directory).

Every link was opened and checked for reachability while writing this list. Entries without a public homepage are linked to their official repository instead.
