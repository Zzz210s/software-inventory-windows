## 范围与整理方法

本清单来自 2026-09-15 对 `E:\` 盘(本机 Windows 软件盘)顶层的扫描结果,一行对应一个已安装程序。

以下非软件项已排除:`$RECYCLE.BIN`、`Config.Msi`、`System Volume Information`(系统数据),以及 `0-cargo-target`(Rust 构建产物目录)。

所有链接在整理时都做过可达性检查;没有公开主页的条目改为链接其官方仓库。
